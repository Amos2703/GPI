Halaman Admin

Karena web ini di-hosting di GitHub Pages (statis), data pendaftar tersimpan di Formspree dan bisa dilihat langsung dari dashboard Formspree.

Cara melihat data pendaftar:

  1. Login ke formspree.io
  2. Buka form yang sudah kamu buat
  3. Klik tab "Submissions"
  4. Data bisa di-export ke CSV dari sana
